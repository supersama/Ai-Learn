## 前端的专业
### 三权分立
- html 负责结构
   盒子 div>div
   html 树状结构
   emmet 快捷输入 css 选择器 语法
   举例：.clock>.clock-face>(.hand*3)
   div 可以省略
   .clock →类名选择器
   >  子元素选择器
   
- CSS 层叠样式表
   负责样式
- JS  行为（事件）
- 模块化， 职责分离， 一个文件一个功能
- CSS link 在头部引入，更早的和html结合，更快的看到静态页面
- 页面看到后，再添加js 行为 
   script 如果放在head 会阻塞html和css结合
   script 放到 body 的结束之前
- 网页每快0.1s，用户的满意度，付费增加1000w
