## plan mode 
   /plan
   在cluade终端输入，可以进入规划模式
   降低了prompt门槛
   通过询问一些问题，帮助我们组织Prompt，使我们更方便描述我们的需求。

## cc基础指令
   /        下一个cc的指令
   
   /plan    开启规划模式 --适合工作
   
   /init    cc对这个项目了解的初始化 
   --面试例题：/init 是做什么用的 cc解析整个项目，并生成一个简介
