# Landing page——落地页

Landing page 的Prompt 规则
举例：一个食品外卖的落地页
## 项目需求
-  为一款名为Foodiez的美食外卖移动端应用，搭建一款现代化、自适应的落地营销页面。
## 设计需求
-  打造高转化营销落地页，推广这款外卖APP，直接传递产品核心价值，引导用户下载应用。
## 技术栈
-  使用以下开发技术：
-React + TypeScript
-Tailwind CSS 样式框架
-Framer Motion 动画库
-组件化架构开发
-移动端优先自适应布局
-符合无障碍标准的语义化HTML
   成品需达到线上生产可用标准
## 视觉风格与设计规范
- 简约现代、高端精致UI界面
- 明快有食欲的外卖美食视觉风格
- 主色调:暖橙色（#FF6B35）
- 中性色：纯白、浅灰底色
- 柔和阴影、超大圆角（两倍超大圆角）
- 流畅细腻的微交互动效
- 高清美食实景占位图
- 字体风格：醒目、亲和易懂、阅读性强
- 布局留白充足，视觉层级清晰分明
## 页面整体结构
1.导航栏
- 品牌LOGO：Foodiez
- 导航菜单：使用教程、入驻餐厅、用户评价、立即下载
- 滚动页面时固定置顶
- 行动按钮：立即下载APP

2.首页主视觉区
左侧内容：
- 主标题：心仪美食、极速送达
- 副标题：阐述产品核心优势
- 应用商店、谷歌应用商店下载按钮
- 实力背书标识： 用户评分、配送时效、合作餐厅数量

右侧内容
- 展示搭载APP界面的苹果手机样机
- 悬浮动态美食卡片、配送状态元素

3.口碑实力区
- 合作连锁餐饮食LOGO展示栏
- 用户真实好评卡片（含卡片、昵称、评价文案）
- 五星星级评分展示

4.使用流程区（三步极简流程）
- 每个流程搭配：图标/插画、流程标题、简短说明
流程顺序：浏览周边餐厅→一键快速下单→极速配送到家

5.核心功能亮点区
图文左右交替双栏布局，配图+功能文案
核心功能：
- 订单实时轨迹追踪
- 个性化美食智能推荐
- 极速一键结算下单
- 精选本地特色美食门店
配页面滚动触发式轻量动画
6.APP页面预览区
横向滑动手机样机展示，每一张界面展示一项核心使用功能
7.福利活动横幅
文案：首单外卖免费配送
-视觉重点突出
-引导
8.终极引流转化区
- 超大加粗宣传标语
- 文案：下载Foodiez，尽享极速美食配送服务
- 双平台应用下载按钮
-渐变底色/主色纯色背景
9.页脚区域
- 品牌LOGO
- 全站导航链接
- 社交媒体图标
- 应用下载入口
- 版权声明
