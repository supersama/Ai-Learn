### Prompting 提示词

### create an app with AI
Prompting 清晰的指令
- 继续Prompt 
     vibe coding
     **Goal** 帮我创建一个网站，可以帮我写生日贺卡，当我提供一个人的姓名，年龄，爱好时，它应该给我返回一条有趣的消息
     **input**
     **output** 
- 加上节日风格的标题和配色，让他更好看一些
- 把卡片放在右侧展示，让它看起来像生日贺卡的内页。
     **layout**
     **features**
- 在页面顶部加一个有趣的标题。另外，不要替换掉就卡片。
而是保留他们并叠放在新卡片的下方。

vibe coding 日常！ 当使用AI写代价时，通常从一组基本指令开始
看看得到了什么，然后反复告诉AI我想怎么改进

当构建软件时，有一些基本的构建块（building blocks）
可以包含在提示词中。

## Prompt basic rule
building blocks

Goal（目标清晰） + Input(用户输入) + Output(输出)
+ Layout(布局) + Features(特色 灵活)
