# 3D 游戏之物理模型世界

## AI Native 思维
面试场景题：
请你设计一段Prompt，做一个3D小世界
能自己点格子放草、树、房子等，搭建一个属于自己的村庄。

原型

## 我想要的体验  
- 一打开网页能看到一个8×8左右的世界，立刻能玩
- 鼠标点格子放置物品（ 草地，土路，水，石头，树，房子，擦除，七个工具）
- 拖拽转视角、滚轮缩放
- 鼠标悬停的格子有视觉反馈
- 关闭网页，下次打开还在
- 能切换三个不同的世界
- 一个"重置按钮"按钮给我生成一个程序化生成的小村庄（有水塘、石堆、几栋房子、几颗树、联通的小路）
- 一个"清空"按钮全变成草地
- 首次打开有个简短操作提示（"拖拽旋转、滚轮缩放、点击放置"之类），几秒后自动淡出。
## 技术架构
- 单页面、零构建、直接双击html就能打开
- 文件不超过3个，一个html，一个css，一个js
- three.js 用CDN引入（r128版本），不要ES nodute,不要 import map，不要npm
- 不要React/Vue/TypeScript/Webpack/Vite/OribtControls
- 所有3D物体用Three.js内置几何体（Box、Cone、Cylinder、Icosahedron等）拼，不要用外部
模型或站点
## 视觉方向
- “积木玩具”风：颜色饱和，对比明确
- 背景是奶油色或者米色（CSS处理，不是Three.js的天空），不要做天空，不要地平线-光照要
“日光”感而不是“演播室白炽灯”——草地不要被照得发白
- 阴影要柔，不要硬切

## UI风格

- 顶部一个标题面版，一个存档工具（下拉+重置+清空按钮）
- 底部层中浮一个工具卡片栏，每个工具卡片有emoj图标+中文标签
- 右下角一个小地图（canvas 2D），弱视当前世界，地形用色块，树和房子用阴影
- 全部面板采用浅色墨砂玻璃风格（半透明+模糊背景），菱角

## 代码组织
- HTML 只放结构和引用
- CSS 写所有外观
- JS包成IIFE，逻辑分段（场景/关照/数据/工厂/交互/持久化/小地图/启动），用注释分隔
- 数据用'world[x][z] = {terrrain,kind}'，所有写入走唯一入口（比如 set(cell)）

## ollama 
本地大模型管理平台，安装一些开源大模型
具身智能（机器人） 工业 4.0 万兆宽带，本地算力（黑盒子硬件，理想livus 汽车）

大模型就是由海量权重**参数**构建的概率映射**函数**，输入语义序列，通过参数运算
拟合语言规律，生成连贯合理的输出结果。
LLM 数学公式
y=fθ(x)

x: 输入文本向量
y：输出文本序列
θ：全部模型参数（权重）
fθ 大模型映射函数
